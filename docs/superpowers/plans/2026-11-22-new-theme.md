# Plan: static deploy (#19) and new theme (#16)

Design: `docs/superpowers/specs/2026-11-22-new-theme-design.md`.

## What changes

Production stops running `hugo server -D`. It serves a static build from nginx, with a Pagefind search index. Then every page moves to style B: a clean blog with a terminal flavor, dark mode, a typing intro on the home page, and a search popup.

## How the work runs

PR A and PR B each get one owner subagent, a `pstack:poteto-agent` on the configured feature model (`sonnet`). The two owners work in separate worktrees, so they share no files while they build. Each owner runs its commits in order and verifies each one. I review every diff and rerun the checks myself before I report a commit as done.

## What stays unproven until it runs

- How the typing intro and stagger feel on a slow phone. The checks prove timing in headless Chromium only.
- Whether Watchtower picks up the nginx image cleanly after the rollout. PR A's rollout step checks it on the live server.
